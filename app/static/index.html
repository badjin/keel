Keel

Knowledge base and hooks for AI coding agents

Install steps

Install / Hooks

1. Hooks

Hooks are small scripts that automatically step in at specific moments of an agent session. See below on the lifecycle rail when each hook runs. Clicking a card on the rail jumps to that hook's list.

The KB path is set in the Knowledge Base tab.

Claude Code is also selected, so Grok will read its hooks from ~/.claude/settings.json — no separate Grok hook file is written.

Grok's existing status line uses a form this installer cannot wrap. Set the Keel status line in ~/.grok/config.toml by hand.

After install, approve the new hooks in Codex — see "Trust the new hooks in Codex" below.

1Session start (SessionStart)

2Request submitted (UserPromptSubmit)

3Before tool use (PreToolUse)

4After tool use (PostToolUse)

5Answer finished (Stop)

6Session end (SessionEnd)

Trust the new hooks in Codex

  1. Open a terminal.
  2. Run codex.
  3. Type /hooks.
  4. Approve the Keel hooks listed there.

Install / Knowledge Base

2. Knowledge Base

The knowledge base is created with the following structure.

index.md Knowledge base entry point
schema.md Folder structure and page-writing rules
raw/ Unprocessed raw session records
wiki/ Organized topic pages
repos/<name>/ Pages generated from repository history
Knowledge base location

An empty new folder is fine — it will be created if it doesn't exist.

      Undo order

      The order matters — if you delete ~/.keel before removing the hooks, the scripts the already-registered hooks point to disappear, and Claude Code / Codex / Grok can error out and get stuck.

      1. Remove the hooks first. On the Hooks tab, keep the Claude Code, Codex, and Grok checkboxes on, then press the "Remove all kit hooks" button. If you also want the installed knowledge base skills removed, turn on the "Also remove skills" checkbox.
      2. Only then delete ~/.keel yourself. The knowledge base folder itself is left alone.

      The hooks = true line in ~/.codex/config.toml is not removed by this procedure. Remove it yourself only if you are sure nothing else needs it.

      What this program changes: the hook entries in ~/.claude/settings.json / ~/.codex/hooks.json / ~/.grok/hooks/keel.json, the status line in ~/.grok/config.toml, hooks = true in ~/.codex/config.toml, the knowledge base skills under ~/.claude/skills, ~/.codex/skills, and ~/.grok/skills, the .bak-* backup files left next to them, and ~/.keel itself.
