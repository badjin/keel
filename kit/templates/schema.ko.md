# 스키마

## 폴더 구조

- `index.md` — 위키 진입점. 저장소/로컬 폴더/주제 섹션에서 각 페이지로 링크한다.
- `schema.md` — 이 파일. 폴더 구조와 페이지 작성 규칙.
- `raw/sessions/` — 처리되지 않은 세션 원본 기록. 사람이 손으로 고치지 않는다.
- `wiki/` — 정리된 주제별 페이지.
- `repos/<name>/` — 저장소 히스토리에서 생성된 페이지 (index, timeline, areas).
- `local/<name>/` — 로컬 폴더에서 생성된 인덱스 페이지.

## 페이지 규칙

- 한 페이지에는 한 주제만 담는다.
- 페이지 맨 위나 적당한 위치에 `## Last Updated: <날짜>` 줄을 둔다.
- 관련 페이지는 양방향으로 `[[페이지이름]]` 링크를 건다 — 이 페이지에서 저쪽으로, 저쪽에서 이
  페이지로.
- `raw/` 는 원자료다. 정리해서 `wiki/` 로 옮기기 전까지는 손으로 편집하지 않는다.

## 위키 관리

- 고아 페이지와 깨진 링크는 저절로 고쳐지지 않는다.
- 가끔(예: 한 묶음의 변경 뒤나 매주) 에이전트에게 위키 린트(wiki-lint)를 돌려 달라고 한다.
- 세션이 끝나면 짧지 않은 세션에 한해 위키가 자동으로 갱신될 수 있다(`wiki-auto-update` 훅,
  선택한 CLI 를 한 번 더 실행하므로 그 쿼터를 쓴다). 판단 기준과 끄는 방법은 README 참고.
